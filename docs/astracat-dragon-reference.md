## Clean-room токены

Из CSS снимков, без `darkreader`-переменных: `#1a76e2` primary, `#075bbe` hover, `#1b88fe` active, `#202e3b` header, `#1f364a` основной текст, `#e9f2ff` selected, `#dbe8ff` hover, `#c1daff/#aeceff` selected table rows. Размеры: 12/14/16/18/20/24 px, spacing 2/4/6/8/12/16/20/24/32/40/48/64/80/96 px, page padding 20 px, sidebar 265 px, control 32 px, radius 3 px.

## Повторяющиеся паттерны

- Тёмная верхняя строка, компактная подстрока, постоянное меню, вкладки разделов.
- Таблицы с панелью действий, фильтром, поиском, выбором строк и постраничной навигацией.
- Формы с 32-px полями; модальные диалоги и последовательные мастера.
- Все ASTRACAT-компоненты лежат в `frontend/src/components/astracat/dragon.tsx`, а экранная сборка — в `frontend/src/pages/astracat-billing.tsx`.

## Подключение данных

Маршрут `/billing` использует существующую клиентскую авторизацию и не имеет демонстрационного набора данных. Экран читает профиль, баланс, платежи, VPN-подписки, устройства, обращения, тарифы и реферальную статистику через текущие `/api/client/*` и `/api/public/tariffs` контракты. Создание обращения, заказ с баланса, создание платежа ЮKassa и настройка автопродления используют существующие мутации API.
